🚴 AdventureWorks Sales Dashboard (Power BI Project)
📌 Project Overview
The AdventureWorks Sales Dashboard is an interactive business intelligence solution developed using Microsoft Power BI to analyze and monitor sales and profitability performance across different regions, product categories, sales channels, and customer segments.
This project focuses on identifying revenue trends, regional performance gaps, customer buying behavior, and product‑level profitability by comparing Current Year (CY) performance with the Previous Year (PY) using Year‑over‑Year (YoY) analysis.

🎯 Project Objective
The primary goal of this dashboard is to enable stakeholders to:

Track overall sales & profit performance
Identify declining or loss‑making regions
Monitor category & product‑level profitability
Compare sales channel performance (Internet vs Reseller)
Analyze monthly sales trends
Understand customer purchase contribution
Perform YoY growth analysis across business dimensions
