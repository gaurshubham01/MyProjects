📊 Defect Analysis Dashboard (Power BI)
🧾 Project Overview
The Defect Analysis Dashboard is developed using Power BI to monitor, analyze, and visualize production defect data. The objective of this project is to identify recurring defect patterns, track performance metrics across inspectors and shifts, and highlight critical areas that require quality improvement through data‑driven insights.

🚀 Key Features

Interactive dashboard with dynamic slicers for real-time filtering
Time-series analysis to monitor defect trends over specific periods
Inspector-wise performance analysis to identify reporting patterns
Shift-wise defect comparison for operational efficiency evaluation
Category-based defect distribution for root cause identification
Advanced data visualizations including:

Treemap Chart
Radar Chart
Funnel Chart
Line & Bar Graphs




📌 Business Insights Derived

A large proportion of defects are concentrated within limited defect categories, indicating potential process bottlenecks
Shift B consistently records a higher number of defects compared to other operational shifts
Specific inspectors are associated with a significantly higher defect detection rate
Defect occurrences show noticeable fluctuations across different time intervals
Process inefficiencies and operational gaps can be identified through shift-based defect comparison


🛠️ Tools & Technologies Used

Microsoft Power BI
Data Cleaning & Transformation
DAX (Data Analysis Expressions)
Data Visualization Techniques
Interactive Reporting


🎯 Project Outcome
This dashboard provides enhanced visibility into quality-related issues by identifying defect-prone processes and performance gaps. It supports stakeholders in making informed, data‑driven decisions, ultimately contributing to continuous process optimization and overall quality improvement.
